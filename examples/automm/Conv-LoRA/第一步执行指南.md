# 🎯 第一步执行指南（问题已解决）

## 问题原因

你遇到的错误是因为 **conda 环境未激活**：
- pip 安装包到了 `conv-lora` 环境（Python 3.10）
- 但 `python` 命令指向 base 环境（Python 3.12，没有 pandas）

## ✅ 解决方案

**每次运行前，先激活 conda 环境**。

---

## 🚀 立即执行（第一步）

### 方式 1：一键运行完整流程（最简单）

```bash
# 激活环境 + 运行完整 pipeline
source /root/miniconda3/etc/profile.d/conda.sh && \
conda activate conv-lora && \
cd /root/autodl-tmp/works/autogluon/examples/automm/Conv-LoRA && \
bash run_full_rl_pipeline.sh isic2017
```

**这会自动完成**：
1. 训练基线 Conv-LoRA（如果没有）
2. BC 预热
3. RL 训练
4. 评估

**总耗时**：~1.5 小时（L20，含基线训练）  
**如果已有基线**：~45 分钟

### 方式 2：分步执行（更可控）

#### 第一步：激活环境

```bash
source /root/miniconda3/etc/profile.d/conda.sh
conda activate conv-lora
cd /root/autodl-tmp/works/autogluon/examples/automm/Conv-LoRA
```

**验证环境**：
```bash
which python
# 应该输出: /root/autodl-tmp/envs/conv-lora/bin/python

python -c "import pandas; print('✓ 环境正确')"
# 应该输出: ✓ 环境正确
```

#### 第二步：训练基线（如果没有）

```bash
python run_semantic_segmentation.py \
  --task isic2017 \
  --rank 3 \
  --expert_num 8 \
  --num_gpus 1 \
  --per_gpu_batch_size 1 \
  --batch_size 4 \
  --output_dir outputs_baseline
```

**等待完成**（~1 小时），查看结果：
```bash
cat outputs_baseline/metrics.txt
```

#### 第三步：BC 预热

```bash
python rl_bc_routing_policy.py \
  --task isic2017 \
  --model_path outputs_baseline/ \
  --output_dir bc_warmstart/ \
  --num_epochs 5 \
  --max_samples 2000 \
  --device cuda
```

**耗时**：~7 分钟（L20）

#### 第四步：RL 训练

```bash
python rl_train_routing_policy.py \
  --task isic2017 \
  --output_dir rl_routing/ \
  --warmstart bc_warmstart/routing_bc.pt \
  --num_experts 8 \
  --rank 3 \
  --num_layers 12 \
  --lr 1e-4 \
  --max_steps 6000 \
  --batch_size 12 \
  --kl_coef 0.05 \
  --entropy_coef 0.01 \
  --adapter_l2_coef 0.001 \
  --compute_budget 1e10 \
  --use_lagrangian \
  --ckpt_interval 500 \
  --vis_interval 100 \
  --mixed_precision \
  --device cuda
```

**耗时**：~30 分钟（L20）

**同时监控**（新终端）：
```bash
source /root/miniconda3/etc/profile.d/conda.sh
conda activate conv-lora
tensorboard --logdir rl_routing/logs --port 6006 --bind_all
```

#### 第五步：评估

```bash
python rl_eval_routing_policy.py \
  --task isic2017 \
  --ckpt_path rl_routing/checkpoints/final.pt \
  --output_dir eval_results/ \
  --num_experts 8 \
  --rank 3 \
  --num_layers 12 \
  --save_heatmaps \
  --device cuda
```

**查看结果**：
```bash
cat eval_results/summary.json
```
