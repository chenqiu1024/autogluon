### 然后运行RL训练（修复版）

```bash
export HF_HUB_OFFLINE=1

python rl_train_routing_policy.py \
  --task isic2017 \
  --output_dir rl_routing/ \
  --warmstart bc_warmstart/routing_bc.pt \
  --model_path AutogluonModels/ag-20251116_011442/epoch=3-step=2000.ckpt \
  --num_experts 8 \
  --rank 3 \
  --num_layers 32 \
  --lr 1e-4 \
  --max_steps 6000 \
  --batch_size 4 \
  --kl_coef 0.05 \
  --entropy_coef 0.01 \
  --adapter_l2_coef 0.001 \
  --compute_budget 1e10 \
  --use_lagrangian \
  --imbalance_weight 0.01 \
  --lagrangian_lr 0.001 \
  --ckpt_interval 500 \
  --vis_interval 100 \
  --mixed_precision \
  --device cuda
```

**重要变化**：
1. ✅ 添加了 `--model_path` 参数
2. ✅ 减小了 `--batch_size` 从12→4（更稳定，避免OOM）

**预计时间**：~30-40分钟（L20）
