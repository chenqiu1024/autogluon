### 步骤2：RL训练（~30-40分钟，L20）

**完整训练（6000步）**：

```bash
export HF_HUB_OFFLINE=1

python rl_train_routing_policy.py \
  --task isic2017 \
  --warmstart bc_warmstart/routing_bc.pt \
  --model_path AutogluonModels/ag-20251116_011442/epoch=3-step=2000.ckpt \
  --output_dir rl_routing/ \
  --num_experts 8 \
  --rank 3 \
  --num_layers 32 \
  --lr 1e-4 \
  --max_steps 6000 \
  --batch_size 4 \
  --kl_coef 0.05 \
  --entropy_coef 0.01 \
  --adapter_l2_coef 0.001 \
  --compute_budget 1e10 \
  --use_lagrangian \
  --imbalance_weight 0.01 \
  --lagrangian_lr 0.001 \
  --ckpt_interval 500 \
  --vis_interval 100 \
  --mixed_precision \
  --device cuda
```

## 🔍 训练过程中观察的关键指标

### TensorBoard中应该看到：

1. **train/reward**：
   - 初始：~0.75（主要是IoU贡献）
   - 目标：逐步上升

2. **train/iou**：
   - 应该稳定在0.70-0.80
   - 如果>0.775（基线），说明RL改进了路由

3. **train/flops**：
   - 应该围绕compute_budget振荡
   - 观察dual_alpha是否收敛

4. **loss/kl**：
   - 应该在0.01-0.1范围
   - 太高（>0.2）说明policy偏离太远

5. **train/imbalance**：
   - 初始：~0（均匀，来自BC）
   - 可能：增加（policy学习专注某些专家）

6. **train/gates_dist（histogram）**：
   - 观察专家使用是否分化
   - 不再完全均匀 = policy在学习

## 🔧 如果训练中遇到问题

### OOM（显存不足）
```bash
--batch_size 2  # 减小batch
```

### 训练不稳定（reward剧烈波动）
```bash
--kl_coef 0.1  # 增大KL系数
--lr 5e-5  # 降低学习率
```

### Reward不上升
```bash
--entropy_coef 0.02  # 增加探索
--kl_coef 0.02  # 减小约束，允许更多探索
```

### 想要更快看到结果
```bash
--max_steps 3000  # 减少步数（可能已够）
--batch_size 8  # 增大batch（如果显存够）
```
