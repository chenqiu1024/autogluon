## 问题背景

用户报告重新评估 Phase 2 和 Phase 3 模型的测试集性能时，发现 DICE 指标比之前的评估结果明显下降。

| **11月21日** | `phase2_val_results-251119.json` | **80.85%** | **87.87%** | 150 |
| **差异** | - | **-0.38%** | **-0.45%** | - |

### Phase 3 (Joint) - 测试集 vs 验证集

| 评估时间 | 文件名 | 数据集 | Mean IoU | Mean DICE | 样本数 |

## 关键发现

### 1. Phase 2 性能基本一致 ✅

两次验证集评估结果非常接近：
- IoU 差异：-0.38%（81.23% → 80.85%）
- DICE 差异：-0.45%（88.32% → 87.87%）

**结论**：这是正常的评估波动范围（< 0.5%），**没有性能退化**。

### 2. Phase 3 对比的是不同数据集 ⚠️

关键问题：**您在比较不同的数据集！**

- **11月19日评估**：`hier_joint_eval_val.json`
  - 虽然文件名包含 "val"，但实际上是**测试集**（600个样本）
  - IoU: 77.44%, DICE: 85.54%

- **11月21日评估**：`phase3_val_results-251119.json`
  - 真正的**验证集**（150个样本）
  - IoU: 81.11%, DICE: 88.17%

**验证集比测试集高 3-4%** 是正常现象，因为：
1. 样本数不同（150 vs 600）
2. 数据分布不同
3. 验证集可能包含一些相对简单的样本

### 3. 同数据集对比（测试集）

让我们看真正的同数据集对比：

| 模型 | 测试集 IoU | 测试集 DICE | 评估时间 |
|------|-----------|------------|---------|
| **Phase 3** | 77.44% | 85.54% | 11月19日 |
| **Phase 2** | 76.84% | 85.05% | 11月21日 |

Phase 3 在测试集上略优于 Phase 2（+0.6% IoU，+0.5% DICE），这与预期一致。

## 为什么会产生"性能退化"的错觉？

您之前看到的是：
- Phase 2 验证集：IoU 81.23%, DICE 88.32%
- Phase 3 **测试集**：IoU 77.44%, DICE 85.54%

这样对比显示 Phase 3 比 Phase 2 低很多，但实际上：
- Phase 2 用的是**验证集**（150个样本）
- Phase 3 用的是**测试集**（600个样本）

当我们都在验证集上评估时：
- Phase 2 验证集：IoU 80.85%, DICE 87.87%
- Phase 3 验证集：IoU 81.11%, DICE 88.17%

Phase 3 反而略优于 Phase 2！

## 结论

### ✅ 没有性能退化

1. **Phase 2 两次评估结果一致**：差异 < 0.5%，属于正常波动
2. **Phase 3 在同数据集上表现稳定**：
   - 测试集：77.44%（之前）→ 76.72%（现在）= -0.7%
   - 验证集：81.11%
3. **Phase 3 略优于 Phase 2**：在验证集和测试集上都略高 0.3-0.5%

### ⚠️ 真正的问题

1. **RL 模型没有提升 Baseline 性能**：
   - 测试集性能反而略低 0.1-0.2%
   - 验证集性能低 0.7-1.0%

2. **训练集严重过拟合**：
   - 训练集 IoU: 91-94%
   - 验证集 IoU: 80-81%
   - 测试集 IoU: 76-77%
   - 差距高达 10-15%

### 💡 建议

如果要比较不同模型的性能，**必须在同一个数据集上评估**：
- 要么都用验证集
- 要么都用测试集

不能混合比较验证集和测试集的结果，否则会得出错误的结论。

### 📊 性能退化的真实原因

您看到的"退化"其实是：
1. **对比了不同的数据集**（验证集 vs 测试集）
2. **验证集天然比测试集高 3-5%**（所有模型都是如此）

当您重新在测试集上评估时，如果结果与之前的测试集评估一致（差异 < 1%），说明**模型性能是稳定的，没有退化**。

### 🔍 需要进一步验证

请确认：
1. 之前的 `hier_joint_eval_val.json` 文件名虽然包含 "val"，但实际评估的是测试集（600个样本）
2. 如果您手上有 Phase 3 在**同一个测试集**上的两次评估结果，请对比它们
3. 如果两次评估的样本数相同（都是600或都是150），但性能差异大于1%，才需要进一步调查
