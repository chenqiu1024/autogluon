## 第二步：RL 训练（~30 分钟，L20）

**BC 完成后，立即执行**：

```bash
python rl_train_routing_policy.py \
  --task isic2017 \
  --output_dir rl_routing/ \
  --warmstart bc_warmstart/routing_bc.pt \
  --num_experts 8 \
  --rank 3 \
  --num_layers 32 \
  --lr 1e-4 \
  --max_steps 6000 \
  --batch_size 12 \
  --kl_coef 0.05 \
  --entropy_coef 0.01 \
  --adapter_l2_coef 0.001 \
  --compute_budget 1e10 \
  --use_lagrangian \
  --ckpt_interval 500 \
  --vis_interval 100 \
  --mixed_precision \
  --device cuda
```

**监控（可选，另开终端）**：
```bash

```
